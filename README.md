# Training Tasks

A collection of Java projects and coding exercises created for practice and coding interview preparation.

## Projects

- **In-Memory Database** — key-value storage with nested transactions, commit and rollback support.
- **File System** — in-memory file system with directories, files, reading, listing and deletion.
- **Room Reservation System** — room booking system with overlap validation, cancellation and sorted reservations.
- **Event Processor** — in-memory event processor with checksum validation, time-window handling and average calculation.

## Focus

- Java
- Data structures and algorithms
- Object-oriented design
- In-memory systems
- Unit testing with JUnit
- Coding interview preparation
